# Testing agent instructions

Read root `AGENTS.md` and `docs/agents/README.md`.

Prioritize reproducible synthetic GTFS fixtures, offline pack integrity, date/calendar exceptions, overnight service, transfer/return feasibility, missing feed behavior, and user-facing source warnings. Never assert a live source or device is tested without running it. Do not fetch live transit data in deterministic unit tests. Record exact commands, results and untested platforms.
