# Provisional visual identity

**Concept:** transit network as a tool for both *getting there* and *discovering somewhere new*.

- Dark navy background with high-contrast white train, bus and tram symbols.
- Intersecting blue, green, orange and purple lines with station dots.
- Subtle New England geography / skyline motif, not an exact geographical map.
- Rounded-square icon silhouette; no tiny lettering.
- Preserve readability at small launcher sizes and in light/dark launchers.
- Test accessibility contrast and color-blind differentiation; color should not be the only route identifier.
- Avoid implying affiliation with operators or government agencies.
- Play Store concept art is not a substitute for production icon assets, Android adaptive icon foreground/background, monochrome themed icon, or 512x512 PNG export.
- Feature graphic concept: 1024x500 wide graphic showing regional network and slogan 'Discover more. Travel with confidence.' without unverified feature badges.
- Screenshot plan (once implemented): offline network map, route browser, trip planner, saved journey, source coverage/expiry panel.

The accompanying `icon-concept.svg` is an original editable vector *interpretation* of the conversation's generated raster icon concept. It intentionally simplifies the geography and transit pictograms. The generated raster mockup remains a separate conversational artifact and has **not** been uploaded to GitHub.
