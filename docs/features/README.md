# Proposed Transit Atlas features

These documents are product specifications, **not implementation claims**.

- [One-tap Get Me There](get-me-there.md): saved destinations, permission-aware origin and offline route feasibility.
- [Privacy-first journey verification](privacy-first-journey-verification.md): optional GPS matching, minimal retention, local-only records and user-controlled deletion.
- [My Transit History](journey-history.md): private color-coded journey maps, ridden network coverage and manual trip records.
- [Adaptive Transfer Timing](adaptive-transfer-timing.md): locally learned walking/cycling pace, conservative transfer estimates and explicit consent.

Read root `AGENTS.md`, `ROADMAP.md`, and `docs/agents/README.md` before implementation. Use focused branches and draft PRs. Do not mark a feature complete without tests.
